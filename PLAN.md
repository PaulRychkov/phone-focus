# phone-focus — план

Приложение для Android, которое следит, какими приложениями ты пользуешься, и передаёт данные боту motivation-bot, чтобы бот помогал меньше залипать в телефоне. Часть экосистемы productivity-ecosystem.

Телефон-цель: OnePlus 13T PKX110 (ColorOS 16 / Android 16). Ставится на любой Android от 7.0.

Заметки исследования со ссылками — в [research/](research/).

---

## Принятые решения

1. **Данные — из `UsageStatsManager`.** Приложение OnePlus «Цифровой комфорт» не нужно и не читается: его база лежит в защищённой папке, без root недоступна. Штатный механизм Android даёт тот же исходный сигнал.
2. **Язык — Go**, как зафиксировано в `productivity-ecosystem/docs/contracts.md`. Вся логика на Go, собирается в библиотеку через `gomobile bind`.
3. **Тонкая обёртка на Kotlin — вынужденно.** Проверено в исходниках x/mobile: `classes.dex` в gomobile вшит константой и содержит один класс `GoNativeActivity`, компиляции Java при сборке нет. А `<service>` и `<receiver>` в Android обязаны указывать на Java-класс. Значит фоновая работа на чистом Go невозможна. Ты выбрал вариант с обёрткой.
4. **Тип напоминания в боте** — `question` (без дневного лимита), схему базы менять не нужно.
5. **Замер примерно раз в 10 минут**, отдельное разрешение на точные будильники не требуется.
6. **Данные шлём по максимуму** — полный снимок: время каждого приложения за окно и за сегодня, запуски, разблокировки, текущее приложение. Хватит, чтобы позже показывать статистику как во встроенном приложении.
7. **Никакой привязки к конкретной сети.** Адрес сервера и токен задаются на экране приложения.

## Как устроено

```
Телефон
  служба переднего плана (Kotlin) — таймер 10 минут
        │
        ├─ читает UsageStatsManager (Kotlin, ~20 строк) → строки «время, тип, пакет»
        │
        └─ передаёт их в Go-библиотеку focus.aar
                 разбор событий → сессии по приложениям → категории
                 → снимок за окно и за сегодня → CloudEvents
                 → отправка по HTTPS; при сбое — очередь на диске
                              │
                              ▼
                    motivation-bot (этап 2)
```

Разделение по языкам:

| Go | Kotlin |
|---|---|
| разбор событий, сессии, категории | чтение `UsageStatsManager` |
| расчёт снимка за окно и за сегодня | служба переднего плана с таймером |
| формат CloudEvents | приёмник загрузки телефона |
| отправка по HTTPS, очередь, состояние | экран настроек и разрешений |

## Состояние

**Сделано и проверено на эмуляторе Android 16 (Pixel 7), запуском приложения, а не только сборкой:**
- приложение: интерфейс на React рисуется, разрешение определяется, замер собирает реальные данные (приложения за окно и за сегодня, текущее приложение, время за день, разблокировки);
- сквозная доставка: включил сбор с адресом → служба сняла замер → тестовый приёмник получил корректный CloudEvent `phone.usage.snapshot` на `POST /ingest/v1/phone-usage`; на экране «Последний замер» показал «Отправлено», очередь 0;
- **дефекты, пойманные запуском и исправленные:** (1) пустой экран — WebView не грузил ресурсы с `file://` из-за CORS; интерфейс собран одним файлом (vite-plugin-singlefile), грузится как единый HTML без внешних загрузок — работает на любом WebView; (2) нативный дубль-заголовок «Focus» над экраном убран (тема без ActionBar), в шапку выведена версия; (3) клавиатура делала автозаглавную `Http://` — Go по такой схеме не слал; поле без автозаглавной + нормализация схемы к нижнему регистру в `Sender`; (4) разрешён cleartext-HTTP, чтобы можно было слать на внутренний адрес по http;
- бот (этап 2 и 3): эндпоинт приёма с токеном, топик `phone.events`, запись в очередь событий, решение о напоминании (`logic.EvaluateDistraction`: порог минут в отвлекающей категории, перерыв между напоминаниями, гейт на выключенный экран) → интервенция `question`, текст пишет LLM. Тесты table-driven, `go vet` чистый.

**Осталось:**
1. Поставить APK на OnePlus и проверить в жизни: замеры при выключенном экране, перезагрузка, не гасит ли ColorOS службу (эмулятор эти OEM-ограничения не воспроизводит).
2. Задать `BOT_PHONE_INGEST_TOKEN` на VM, раскатать обновлённого бота, вписать адрес и токен в приложение.
3. По желанию: гейт на активную focus-сессию помидора, тул `get_recent_phone_usage` для агента, статистика.

## Риски

- **ColorOS выгружает фоновые службы.** Лечится только ручной настройкой на телефоне: автозапуск, отключение экономии батареи и «глубокой оптимизации», закрепление в списке недавних. OnePlus иногда возвращает экономию батареи сам — приложение показывает её состояние на экране.
- **Размер APK 37 МБ** — внутри Go-рантайм под четыре архитектуры. Если мешает, соберём отдельный APK под arm64, будет около 10 МБ.
- **Частые снимки раздувают очередь событий бота** — шлём только при изменении, при необходимости сократим срок хранения для источника `phone`.
